= Rokur gate + ops docs — historical material, not an implementation

These files were copied from a retired ReScript-era Svalinn tree. They are
reference material only: this checkout does not contain the source implementation
they describe, and the API, deployment, testing, and build instructions have not
been verified against the current code. They must not be read as evidence that a
Rokur integration is implemented here or as approval of any current runtime or
language. The replacement language decision is unresolved; see
`../language-and-ecosystem-audit.adoc`.

* `ROKUR-GATE-CONTRACT.adoc` records historical request/response semantics,
  including fail-open behavior. Validate the contract with Rokur's current
  owner/API before implementing it.
* `API.adoc`, `DEPLOYMENT.adoc`, and `TESTING.adoc` are retained operational
  notes only. Their code snippets and commands are stale until revalidated.
* `../../deployment/security/` contains language-independent configuration,
  but still requires deployment/security review before use.
